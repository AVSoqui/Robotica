\chapter{Marco Teórico} 
\label{chap:marco_teorico}

El desarrollo de sistemas roboticos esta formada por gran parte de conocimientos dinamicos y cinematicos, dichos conocimientos permiten modelar, estructurar y controlar el movimiento de los manipuladores. 

Este apartado presenta los conceptos necesarios para que sustentan el control y la simulación de manipuladores robóticos. Se presentan tres conceptos principales para la apta comprension del tema, la cinematica que explica el movimiento, la dinamica explica las fuerzas involucradas y el uso de ROS, una herramienta de software para la simulacion de sistemas roboticos complejos, estos tres puntos formal la base para el desarrollo de soluciones eficientes y precisas en el campo de la robotica mdoerna
